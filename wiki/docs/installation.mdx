# Installation

The Harrower is a standalone mod for **Minecraft Java Edition 1.21.1**, using **NeoForge** and **Java 21**.

Download the mod from [CurseForge](https://www.curseforge.com/minecraft/mc-mods/the-harrower) and install its JAR in the `mods` folder of a compatible Minecraft instance. Do not extract the JAR.

## Single-player

Install NeoForge for Minecraft 1.21.1, then place the Harrower JAR in the instance's `mods` folder. Launch the game with that NeoForge profile.

## Multiplayer

The Harrower includes server-side combat, entities, loot, and items as well as client-side models, animations, and effects. Install the same compatible version on **both the dedicated server and every connecting client**.

## Troubleshooting

If the game refuses to launch, confirm that the Minecraft version, NeoForge version, and Java runtime match the mod's requirements. If a multiplayer connection is rejected, confirm that the server and clients have compatible Harrower installations.

For source code and issue reports, visit [the GitHub repository](https://github.com/adamsilfven/the_harrower).
