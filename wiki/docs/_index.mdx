# The Harrower

**Some things are better left buried. This one isn't staying there.**

The Harrower is a standalone endgame boss mod for Minecraft Java 1.21.1 on NeoForge. It introduces a colossal, fractured-stone creature that does not spawn naturally. Players must seek out a Hollow Fragment and construct a Hollow Cairn to call it into the world.

Defeating the Harrower earns a Hollow Core, used to craft powerful Hollowforged equipment. The encounter is intended for well-equipped players who want a substantial challenge beyond Minecraft's usual bosses.

## Start here

- **Installation:** Install The Harrower on Minecraft 1.21.1 with NeoForge and Java 21. In multiplayer, install the mod on both the dedicated server and connecting clients.
- **Summoning:** The Harrower does not spawn naturally. Find a Hollow Fragment and construct a Hollow Cairn before attempting the ritual.
- **Combat:** Expect devastating melee attacks, ground ruptures, and Hollowing. Prepare a large fighting area and strong equipment.
- **Rewards:** Hollowforged equipment is crafted using Hollow Cores, not dropped directly by the boss.
