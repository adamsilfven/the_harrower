# Hollowforged Crafting Recipes

Every Hollowforged piece is made at a standard crafting table. Each recipe uses **one Hollow Core**, recovered by defeating the Harrower. The patterns below are taken directly from the mod's shipped recipe JSON files.

## Ingredient key

| Symbol | Ingredient |
| --- | --- |
| C | Hollow Core |
| N | Netherite Ingot |
| E | Echo Shard |
| O | Crying Obsidian |
| D | Diamond Block |
| S | Nether Star |
| K | Sculk Catalyst |
| H | Heavy Core |
| B | Breeze Rod |
| · | Empty slot |

## Crown of the Hollow

```text
E E E
N C N
O · O
```

Requires 3 Echo Shards, 2 Netherite Ingots, 2 Crying Obsidian, and 1 Hollow Core.

## Carapace of the Unbroken

```text
N · N
D C D
N S N
```

Requires 4 Netherite Ingots, 2 Diamond Blocks, 1 Nether Star, and 1 Hollow Core.

## Greaves of the Stillborn

```text
N K N
O C O
N · N
```

Requires 4 Netherite Ingots, 2 Crying Obsidian, 1 Sculk Catalyst, and 1 Hollow Core.

## Treads of the Worldbreaker

```text
· · ·
N C N
B · B
```

Requires 2 Netherite Ingots, 2 Breeze Rods, and 1 Hollow Core. The empty top row is intentional.

## Worldshard

```text
N H N
D C D
· B ·
```

Requires 2 Netherite Ingots, 2 Diamond Blocks, 1 Heavy Core, 1 Breeze Rod, and 1 Hollow Core.

## Before you craft

The Hollow Core is consumed by crafting. All five pieces are unbreakable and have distinct powers, so choose which piece to make first based on how you play.

For abilities and controls, see [Hollowforged Equipment](./hollowforged).
