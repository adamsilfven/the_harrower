# Leyline Convergence

Minecraft Java 1.21.1 · NeoForge · Java 21

This repository contains the custom mods behind Leyline Convergence. The first release here is **The Harrower 1.0.0**: an optional endgame boss, its summoning ritual, and the Hollowforged equipment made from what it leaves behind.

The Harrower works on its own. Leyline Convergence Core is optional and adds the personal Leyline integration.

Release files and documentation are being added under `harrower/`.
