# The Harrower 1.0.0

Public release for Minecraft Java 1.21.1, NeoForge 21.1.259 and Java 21. Install the same consolidated JAR on server and clients, replacing older Harrower/Hollowforged/Hollow Fragment JARs. LC Core is optional and unchanged.

Includes the Harrower boss, reusable Hollow Cairn ritual, Hollow Fragment, Hollow Core, Hollowforged equipment and crafting, varied endgame rewards, and loot delivery during the death crumble.

This promotes the user-tested 0.6.2-rc.2 build. All existing gameplay classes, visual/sound assets, recipes and loot are byte-identical. Changes are limited to release version/public descriptions in NeoForge metadata and an added license notice. Existing registry IDs and component versions remain compatible.

Clean compilation and installed-JAR dedicated-server validation passed. See VALIDATION.md and evidence for scope and limits. No new rendered-client test or full installed-LC integration test is claimed. This package is ready for distribution; it has not been published to a mod hosting service.
